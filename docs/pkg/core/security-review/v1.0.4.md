## サマリー

致命的な脆弱性は **検出されず**。本バージョンの差分は **バージョン引き上げと devDependencies の更新のみ** で、`packages/core/src/` の実装コードへの変更は無い。ランタイム依存は引き続き **空** で、配布物の攻撃面に変化なし。

差分の中身:

- `package.json`: `version` を 1.0.3 → 1.0.4
- `package.json` (devDependencies): `tsx` ^4.23.11 → ^4.23.12 (patch)
- ルート `mise.toml`: node 24.17.0 → 24.19.0 (同一 LTS メジャー内)、pnpm 11.21.0 据え置き
- `pnpm-lock.yaml`: 上記とワークスペース全体の更新に追従

## 良い点 (Strengths)

- **実装コード非変更・ランタイム依存ゼロを維持** — 更新はすべて開発時ツール (tsx の patch) に限定され、パーサー / ファイル I/O / 公開 API の経路は v1.0.3 から不変。
- **lockfile の健全性 (ワークスペース全体で検査)** — 追加された解決エントリー 24 件 (削除 22 件、純増 2 件) はすべて既定レジストリ (npmjs) の semver 解決で `sha512` integrity 付き。git / http tarball 解決、`.npmrc` によるレジストリ変更、`hasInstallScript` の新規追加、ダウングレードはいずれも無し。主要エントリー 6 件はレジストリの `dist.integrity` と実測一致を確認済み。
- **検証済** — `pnpm check` / `pnpm typecheck` / `pnpm test` (core 427 件) / `pnpm build` が全通過。

## 所見 (Findings)

### `feat/prepare-release` 差分起因の新規 Finding

**該当なし**。実装コードへの変更が無く、新規の入力経路・依存・実行コードのいずれも導入されていない。

v1.0.0 の LOW-1〜LOW-6、v1.0.2 の INFO-1 / INFO-2 (MP4 末尾ゴミ)、v1.0.3 の INFO-1 / INFO-2 (PIC 変換 / MIME スニッフィング) はいずれも本差分で変更されたコードに該当せず据え置き (悪化なし)。

## 次回更新時のチェックリスト

core のバージョンを上げる PR では新しい `v1.x.y.md` を作成し、以下を再評価:

- [ ] v1.0.0 の LOW-1〜LOW-6 (シンボリック リンク follow ほか) が当該 PR で悪化していないか
- [ ] v1.0.3 チェックリストの継続項目 (`detectMime` へのアクティブ コンテンツ形式追加時の再評価、v2.2 変換対象拡大時の再検証)
- [ ] `dependencies` にランタイム依存を追加した場合は、当該パッケージの既知 CVE を `npm audit` / GitHub Advisory で確認
- [ ] lockfile 更新を伴う PR では、追加エントリーのレジストリ ホスト / integrity / install script の有無を再検査
