## サマリー

致命的な脆弱性は **検出されず**。本バージョンの差分は **devDependencies のバージョン更新とパッケージ バージョンの引き上げのみ** で、`packages/core/src/` の実装コードへの変更は無い。

差分の中身:

- `package.json`: `version` を 1.0.0 → 1.0.1
- `package.json`: `@types/node` 25.9.1 → 25.9.2 / `tsx` 4.22.3 → 4.22.4 / `vitest` 4.1.7 → 4.1.8 (いずれも devDependencies、パッチ更新)
- `pnpm-lock.yaml`: 上記に追従

|  | 件数 |
| --- | --- |
| Critical | 0 |
| High | 0 |
| Medium | 0 |
| Low / Informational | 0 (新規) |

ランタイム依存 (`dependencies`) はゼロのまま変わらず、サプライ チェーン由来の攻撃面に増減なし。更新された 3 件はすべて開発時のみ利用される型定義 / 実行ツール / テスト ランナーのパッチ更新で、配布物には含まれない。

## 良い点 (Strengths)

- **ランタイム依存ゼロを維持** — `dependencies` は引き続き空。本 PR でも実行時のサプライ チェーン面は増えていない。
- **実装コード非変更** — `BufferCursor` の境界チェック、`MmeError` の失敗分類、signature 優先の format detection といった v1.0.0 で確立した防御線はそのまま維持。

## 所見 (Findings)

**該当なし**。実装コードへの変更が無く、新規の入力経路・パース ロジック・ファイル I/O・動的コード実行のいずれも導入されていない。devDependencies のパッチ更新は配布物に影響しない。

## 次回更新時のチェックリスト

core のバージョンを上げる PR では新しい `v1.x.y.md` を作成し、以下を再評価:

- [ ] v1.0.0 で記録した LOW-1〜LOW-6 (シンボリック リンク follow ほか) が当該 PR で悪化していないか
- [ ] `dependencies` にランタイム依存を追加した場合は、当該パッケージの既知 CVE を `npm audit` / GitHub Advisory で確認
- [ ] devDependencies のメジャー アップデート時は、ビルド / テスト経路で新たな postinstall 等の攻撃面が増えていないか確認
