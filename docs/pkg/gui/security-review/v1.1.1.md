## サマリー

致命的な脆弱性は **検出されず**。本 PR の gui 差分は `package.json` の devDependencies range 更新と、`sync-electron-targets` が書き換えた `src/renderer/vite.config.ts` の `target` 1 行 (`chrome150` → `chrome152`) および `mise.toml` の node バージョンのみ。main / preload / renderer の実装コードと IPC 面は不変。

Electron 44 への major 更新については、BrowserWindow の `webPreferences` (`contextIsolation: true` / `nodeIntegration: false` / `sandbox: true`) の既定値変化がないこと、Electron 44 の breaking changes (renderer `clipboard` モジュール削除、`net.request` 変更、`app.isUnityRunning` / 旧 macOS login-item 属性の削除、`select-client-certificate` 変更、ia32 / armv7l / macOS 12 サポート終了) がいずれも gui の使用 API / ビルド対象 (x64 / arm64) に該当しないことを確認した。

lockfile / ツール解決経路のサプライチェーン検査結果は [`../../core/security-review/v1.1.1.md`](../../core/security-review/v1.1.1.md) と共通: 追加 resolution 95 件すべてに sha512 integrity あり、非 registry 参照 0 件、lifecycle script を持つ `electron` / `electron-winstaller` / `esbuild` は `allowBuilds` 登録済み、`pnpm audit` で既知脆弱性なし。

## 良い点 (Strengths)

- **Electron セキュリティ設定が不変** — `src/main/main.ts` は差分なし。`contextIsolation: true` / `nodeIntegration: false` / `sandbox: true`、本番は `loadFile`、`loadURL` は `VITE_DEV_SERVER_URL` 設定時 (開発時) のみ。preload の `contextBridge` 公開面も不変で、renderer からは `ipcRenderer.invoke` 経由の固定 API のみ到達可能。
- **Electron 44 の breaking changes に非該当** — renderer `clipboard` は使わず Web API (`navigator.clipboard.readText()`) を使用。`net.request` / `app.isUnityRunning` / `select-client-certificate` は未使用。使用中の Electron モジュール (`app` / `BrowserWindow` / `dialog` / `ipcMain` / `Menu` / `shell` / `contextBridge` / `ipcRenderer` / `webUtils`) は 44 でも提供される。
- **ビルド ターゲットが実バイナリーと整合** — `electron@44.1.0` の同梱 Chrome 152 / Node 24.19.0 に対し、renderer target `chrome152`、`packages/gui/mise.toml` の node 24.19.0 が一致。tsconfig / main・preload の Vite target (ES2024 / node24) は変更なし。
- **インストール スクリプト ポリシーが維持** — `electron@44.1.0` の `install.js` (バイナリー取得) は `allowBuilds` の `electron: true` で明示許可済み。`electron-winstaller` / `esbuild` はバージョン不変。
- **lockfile の来歴が健全** — core のレポートと同じ検査を通過 (registry / integrity / install script)。追加の推移依存は `powershell-utils@0.2.1` (`open@11` 経由) のみ。
- **検証済** — `pnpm install --frozen-lockfile` / `pnpm typecheck` / `pnpm check` / `pnpm build` / `electron --version` (v44.1.0) / `pnpm test` (gui 289 件) が全通過。

## 所見 (Findings)

**該当なし**。継続中の LOW-2 / LOW-3 / LOW-4 は据え置き (悪化なし)。
