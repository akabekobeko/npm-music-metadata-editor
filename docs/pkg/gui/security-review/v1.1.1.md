## サマリー

致命的な脆弱性は **検出されず**。本 PR の gui 差分は `package.json` の devDependencies range 更新 (15 件) と `test:coverage` スクリプト削除、`sync-electron-targets` が書き換えた `mise.toml` の node バージョンのみ。main / preload / renderer の実装コードと IPC 面は不変。

Electron 44.1.0 → 44.4.2 は同一 major の patch 更新で、`src/main/main.ts` は `contextIsolation: true` / `nodeIntegration: false` / `sandbox: true` を明示しているため 44.x 内の既定値変化に依存しない。`sync-electron-targets` の結果、同梱 Chrome 152 / ES2024 / node24 のビルド ターゲットは不変で、同梱 Node が 24.21.0 になったため `packages/gui/mise.toml` のみ追従した。

lockfile / ツール解決経路のサプライチェーン検査結果は [`../../core/security-review/v1.1.1.md`](../../core/security-review/v1.1.1.md) と共通。gui に固有の点として、名前として新規の推移依存 `cn@0.2.6` (`shadcn@4.21.0` が `tailwind-merge` の代わりに採用) を個別に検証した: npm maintainer は `shadcn` パッケージと同一、repository は `github.com/shadcn-ui/cn`、GitHub Actions からの SLSA v1 provenance attestation 付き、lockfile の integrity は registry と一致、`bin` / `dist` に `child_process` / `fetch` / `eval` の使用なし。`hasBin: true` だが本リポジトリから呼び出す箇所は無い。

## 良い点 (Strengths)

- **Electron セキュリティ設定が不変** — `src/main/main.ts` は差分なし。`contextIsolation: true` / `nodeIntegration: false` / `sandbox: true` を明示、本番は `loadFile`、`loadURL` は `VITE_DEV_SERVER_URL` 設定時 (開発時) のみ。preload の `contextBridge` 公開面も不変。
- **Electron は patch 更新のみ** — `^44.4.2` で 44.x 系を維持。44.4.2 は 2026-09-18 公開の stable。breaking changes は無く、使用中の Electron モジュールは全て提供継続。
- **ビルド ターゲットが実バイナリーと整合** — `electron@44.4.2` (`electron --version` で確認) の同梱 Chrome 152 / Node 24.21.0 に対し、renderer target `chrome152` は不変、`packages/gui/mise.toml` の node 24.21.0 が一致。
- **インストール スクリプト ポリシーが維持** — `electron@44.4.2` の `install.js` (バイナリー取得) は `allowBuilds` の `electron: true` で明示許可済み。`electron-winstaller` / `esbuild` / `msw` はバージョン不変。新規 install script を持つパッケージは 0 件。
- **新規推移依存 `cn` の来歴を確認済** — 上記サマリーのとおり shadcn 本人による SLSA provenance 付き公開。`@pnpm/exe.*@12.4.2` の追加プラットフォーム バイナリー (android / freebsd / ppc64 / riscv64 / s390x) は `os` / `cpu` でゲートされ本ホストには展開されない。
- **lockfile の来歴が健全** — core のレポートと同じ検査を通過 (registry / integrity / install script)。
- **検証済** — `pnpm install --frozen-lockfile --offline` / `pnpm typecheck` / `pnpm check` / `pnpm build` / `electron --version` (v44.4.2) / `pnpm test` (gui 289 件) が全通過。

## 所見 (Findings)

**該当なし**。継続中の LOW-2 / LOW-3 / LOW-4 は据え置き (悪化なし)。

情報のみ: レビュー時点で Electron 44.4.3 (同日公開、Chromium / PDFium / Skia / V8 の upstream backport を含む) が存在するが、pnpm 12 の既定 `minimumReleaseAge` (24 時間) により本 PR の `pnpm update --latest` では解決されなかった。次回の依存更新で自然に取り込まれる。
